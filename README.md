# Danny Duarte Fotografias — Site de Orçamentos

## Estrutura
- Páginas HTML na raiz (index.html + uma página por ensaio)
- assets/logo/logo-header.png -> logo do header (grande, ocupando o topo)
- assets/ensaios/<slug>/hero.jpg -> foto grande de abertura de cada página
- assets/ensaios/<slug>/<tag>.jpg -> fotos da galeria de cada ensaio

## Como trocar uma imagem
Basta substituir o arquivo mantendo EXATAMENTE o mesmo nome (ex: assets/ensaios/gestante/hero.jpg).
Enquanto a imagem não existir, a página mostra automaticamente um espaço reservado (placeholder tracejado) com o nome da tag esperada.
